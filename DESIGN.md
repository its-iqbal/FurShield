# FurShield Design System

## Direction

Clinical-but-gentle. FurShield should feel like a good veterinary clinic:
competent and trustworthy first, warmth used to soften that, never the
other way around. Nothing cartoonish or twee. Nothing sterile or cold.

Do not use Tailwind's default violet/fuchsia/orange scale, default `shadow-lg`,
or Inter for headings. Those are the generic "AI-generated" defaults this
system replaces.

## Color Tokens

| Token | Hex | Usage |
|---|---|---|
| `primary-50` | `#C9DCC9` | tints, subtle backgrounds, hover states |
| `primary-500` | `#7FA087` | primary buttons, active nav, key icons |
| `primary-700` | `#4F6B54` | primary text on light bg, pressed states |
| `accent-500` | `#E29578` | CTAs and highlights ONLY, never backgrounds |
| `info-500` | `#8FB1C7` | vet-portal clinical accents, informational badges |
| `bg-base` | `#FBF7F0` | page background (never pure white) |
| `text-base` | `#33302B` | body text (never pure black) |

Semantic states (success, warning, error, info) must be desaturated toward
this palette, not the default saturated red/green/yellow. E.g. an overdue
vaccination badge should read as a muted clay-red, not stock Tailwind red.

## Typography

- Headings: **Fraunces** (variable serif) — carries the "trusted
  professional, handwritten chart" warmth
- Body: **Work Sans** or **Plus Jakarta Sans** — clean, slightly warmer
  x-height than Inter
- Do not use Inter for headings under any circumstance

## Structural Rules

- Radius: one consistent value across the app, 12–16px. No mixing
  `rounded-2xl` cards with `rounded-full` buttons.
- Shadow: low-opacity, tinted toward `text-base` (warm charcoal-brown),
  never Tailwind's default gray `shadow-lg`.
- Icons: rounded stroke caps, organic paw/leaf motifs over sharp
  geometric icon sets.
- Motion: fades and slides only. No decorative pulse/bounce animations
  (remove `pulse-slow` entirely). Nothing about a vet's office should pulse.

## Component Rules

- **Buttons**: primary-500 fill for main actions, accent-500 reserved for
  the single most important CTA on a screen (e.g. "Book Appointment"),
  never used for more than one element per screen.
- **Cards**: bg-base or primary-50, warm-tinted shadow, consistent radius.
- **Badges/alerts**: desaturated semantic colors per the table above.
- **Forms**: generous spacing, primary-500 focus rings, no harsh red
  validation borders — use the desaturated error tone instead.

## Reference Screens

Landing, main Dashboard, and Health Records are the hand-built reference
screens. Any new screen generated by an AI tool should be checked against
these for consistency, not against the tool's own independent judgment.
